## 五种核心句式

英文技术文档 90% 的句子都是这五种结构的组合。学会识别它们，长句也能拆开。

<div class="pattern-card">
  <div class="pattern-name">① 被动语态</div>
  <div class="pattern-rule">识别：is / are / was + 动词ed &nbsp;|&nbsp; by + 谁 = 由谁执行</div>
  <div class="pattern-example">
    "This method <em>is used</em> to fetch data."<br>
    → 这个方法被用来获取数据
  </div>
</div>

<div class="pattern-card c2">
  <div class="pattern-name">② 条件句</div>
  <div class="pattern-rule">识别：If 开头 → 如果……就……</div>
  <div class="pattern-example">
    "<em>If</em> the value is null, return false."<br>
    → 如果值为空，就返回 false
  </div>
</div>

<div class="pattern-card c3">
  <div class="pattern-name">③ 定语从句</div>
  <div class="pattern-rule">识别：that / which / who → 修饰前面的名词</div>
  <div class="pattern-example">
    "A function <em>that</em> returns a boolean."<br>
    → 一个返回布尔值的函数
  </div>
</div>

<div class="pattern-card c4">
  <div class="pattern-name">④ 祈使句</div>
  <div class="pattern-rule">识别：动词直接开头，没有主语 → 文档在指示你做某事</div>
  <div class="pattern-example">
    "<em>Call</em> this method before rendering."<br>
    → 在渲染之前调用这个方法
  </div>
</div>

<div class="pattern-card c5">
  <div class="pattern-name">⑤ 时间状语从句</div>
  <div class="pattern-rule">识别：when / before / after → 当……时候</div>
  <div class="pattern-example">
    "The callback is triggered <em>when</em> the event is fired."<br>
    → 当事件触发时，回调函数被调用
  </div>
</div>

## 关键技巧

<div class="tip-box">
  <div class="tip-title">拆句主干法</div>
  <div class="tip-content">遇到长句先去掉所有从句，找到"主语 + 动词 + 宾语"的主干，再逐层加从句理解。</div>
</div>

<div class="tip-box">
  <div class="tip-title">容易混淆：request vs required</div>
  <div class="tip-content">request = 请求（名词/动词）&nbsp;&nbsp;|&nbsp;&nbsp; required = 必填的（形容词）。两个词形状很像，但意思完全不同，要特别注意。</div>
</div>

<div class="tip-box">
  <div class="tip-title">fired = triggered = 触发</div>
  <div class="tip-content">技术文档里这两个词完全等价，看到任意一个都理解为"触发"即可。</div>
</div>

<div class="tip-box">
  <div class="tip-title">deprecated 的真正含义</div>
  <div class="tip-content">不是"过期"，是"官方已废弃"。看到它意味着：这个方法还能用，但官方不推荐，将来可能会删除，应该换用新方法。</div>
</div>
